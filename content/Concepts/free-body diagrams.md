#u2 #forces
- (*def.*) used to analyze all the [[force|forces]] acting on an object so that we can determine the **net force** and thus the subsequent *motion* of the object.
- ###### Details:
	- The object or system of objects is *represented by a dot*, and all force vectors *originate from that point*.
	- The [[force]] [[vector|vectors]] need to be labeled with the type of [[force]] **correctly identified**.
	- The [[force]] [[vector|vectors]] need to be in the **correct direction**.
	- The [[force]] [[vector|vectors]] need to be the **correct relative lengths**.
